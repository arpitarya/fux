## ADR-0010 — URL source via consumer-owned middleware

`fux.toml [sources.url]` names a consumer-editable Python file; `fux ingest
--refresh-urls` is the only networked ingest path. Hashed meta by default;
plain ingest stays offline and carries `url:` records forward
byte-identically. **Core gains no adapter, no network code, no dependency.**
Amended in place by ADR-0011 (paths moved into `.fux/`).

## ADR-0011 — the `.fux/` directory as a declared layout

Every child declared committed (`index/`, `sources/`, `middleware/`) or
derived (`runtime/`, `cache/`, `CACHEDIR.TAG`-tagged). Self-describing
`.fux/README.md`; a narrow `.fux/.gitignore` that **never uses `*`**; two
`fux doctor` checks.

**Two things needing Arpit specifically:**

1. ADR-0011 §Alternatives closes the original handoff's open question —
   `.fux/README.md` is generated at **ingest** time, not by `doctor --fix`.
   Reversible; flagged because it was decided by the builder, not by him.
2. The one-line CLAUDE.md layout addition is **proposed, not applied**:
   [`handoff/v0.31.0-claude-md-layout.diff`](../handoff/v0.31.0-claude-md-layout.diff).
   Applying it is part of [W-32](W-32-claude-md-adoption.md).
