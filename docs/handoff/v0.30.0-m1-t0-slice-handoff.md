# Handoff: v0.30.0 M0+M1 — scaffold + the T0 slice

**One-liner:** Build the smallest honest Fux: ingest this repo's own docs
into the canonical committed index and answer questions from it with
citations — no accelerator, no adapters beyond git, no pruning.

**Owner / executor:** Claude Code — **Sonnet**, with one Opus review point
(§11).
**Status:** Ready to build — the plan's gate is closed
([ADR-0003](../adr/0003-pruning-criterion-rerun.md): FAIL accepted,
option E; full postings).
**Stress-tested:** The architecture was council-debated (2026-08-09) and
the format decision is measurement-backed (benches B1–B6 in
[`../compare/index-format.compare.md`](../compare/index-format.compare.md)).
Packaging this slice surfaced three challenges that shaped it:
*(1)* the riskiest assumption is **canonical-writer byte-determinism across
environments**, not retrieval — so R1 is asserted in CI on two platforms,
and the writer's rules are non-negotiables here rather than style notes;
*(2)* "scan is slow" tempts building the accelerator early — **fenced out**:
M1 ships correct-but-193-ms-class queries on a ~200-doc corpus (fine), and
M2 owns speed behind a differential law; *(3)* dogfooding on this repo means
the corpus is small and homogeneous — acceptable *because pruning is gone*
(nothing here depends on corpus statistics behaving), and R2 is defined as
a real question a session actually asks. Residual risk: unicode
normalization differences between macOS and Linux checkouts — settled by
rule in §6, verified by R1.

## 1. Context & background

Two measured gates closed the design: pruning FAILED
([ADR-0002](../adr/0002-pruning-eval-gate.md) →
[ADR-0003](../adr/0003-pruning-criterion-rerun.md)), so the index carries

query path that works on a cold clone with zero derived structure.

## 5. Technical approach (decided — do not re-litigate)

- **Schema:** per the index-format compare §5. Term hashes:
  `blake2b(term_bytes, digest_size=8).hexdigest()` — 16 hex chars.
  Per-field tf arrays ordered per the header's `tf_fields`. Edge grades
  int 0–10. `code` = base64url, no padding. No floats, no nulls, no
  wall-clock anywhere in committed bytes.
- **Sharding:** `shard = blake2b(id_bytes, digest_size=1).hexdigest()` →
  `.fux/index/{00..ff}.jsonl`; lines sorted by `id` within a shard; every
  shard begins with the identical `_format` header line.
- **Canonical JSON:** `json.dumps(rec, sort_keys=True,
  separators=(",", ":"), ensure_ascii=False)` + `"\n"`; text normalized
  **NFC** at ingest (macOS NFD checkouts are the known hazard — this rule
  is what R1 verifies); `id` is the POSIX relative path prefixed `file:`.
- **Scan query:** open each shard, bytes-prefilter on the query's term
  hashes, `json.loads` candidates only; df/N/avg-wlen accumulated in the
  same pass (they are *never stored*); ported BM25F scores; deterministic
  tie-break on `id`.
- **Config:** `fux.toml` minimal — `[sources] dirs = ["docs", "README.md",
  "CLAUDE.md"]`, `[index] shards = 256`. tomllib. No other keys this slice.

## 6. Non-negotiables / constraints

- **Stdlib only** in `src/fux/`. No new dependencies, dev extras aside.
- **Determinism:** same checkout → same bytes, on any OS (NFC rule, sorted
  walks, sorted keys, seeded nothing — there is no randomness to seed).
- **The store is append/replace-by-line** — the writer must produce the
  full canonical shard deterministically; never patch bytes in place.
- **Collision = hard failure** with the colliding terms named.
- **No accelerator, no pruning, no extra adapters** (scope fence §3).
- **Agent-steering files (CLAUDE.md) get proposed diffs, never silent
  edits.** 1 feature = 1 ADR. Worklog every exchange.

## 7. Dependencies & prerequisites

Python ≥ 3.11 and `uv`. CI needs a macos runner for the R1 cross-platform
assertion (already available in `.github/`). No network, no secrets — this
entire slice runs offline.

## 8. Edge cases & risks

- **Empty or binary files in `docs/`** → skip with a recorded reason
  (`fux ingest --list-skipped`), never a crash.
- **Two docs, same `id`** → impossible by construction (path = id); assert
  anyway.
- **Huge single doc** (the paper) → fine; full postings are the design.
- **Non-UTF8 bytes** → skip-with-reason; do not guess encodings this slice.
- **`.fux/` committed noise** → `.fux/index/` IS the committed artifact;
  everything else under `.fux/` (future derived/) is gitignored from day
  one — get the `.gitignore` right *now* so M2 can't leak the accelerator.
- **Tokenizer drift vs archive** → ported tests are the guard; any
  intentional change bumps `analyzer` in the header and is named in
  ADR-0004.
