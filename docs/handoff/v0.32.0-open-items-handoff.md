# Handoff — v0.32.0: the open-items program

**Model: Opus throughout, with two named Sonnet windows** (Phase 0's
mechanical work, and Phase 1's test authoring once the design is fixed).

*Why Opus:* Phase 1's **differential law** is the load-bearing invariant of
the entire tiering story — an accelerator that is subtly non-equivalent to
scan passes a naive suite and poisons every downstream measurement. Phase 0
contains three judgment calls (a pre-registered question that may not move,
a convention contradiction, and an archive-law reading) where the wrong
answer is silent. Model choice is a silent failure mode: an under-powered
model here does not error, it returns confident, plausible, wrong work.

*Where Sonnet is enough, and why it is named rather than assumed:*
Phase 0.1 (file moves + link fixes) is a mechanical rule with an exact
definition of done. Phase 1.4 (test authoring against a frozen design) is
implementation against a written DoD. Everything else is Opus.

## §2 · The laws that bind every phase

Non-negotiable. A change that breaks one of these is wrong even if it
passes tests.

1. **`$0` · stdlib-only · byte-deterministic · offline by default.** No
   floats and no wall-clock in any committed byte. No new runtime
   dependency, at all, for any reason.
2. **One feature → one ADR**, and **every rule, ADR and material decision
   carries a reference** — a paper, a post, or a concrete link. An ADR with
   no reference is incomplete.
3. **A pre-registered threshold may never move.** If a result lands between
   clearly-passing and clearly-failing, write it up as **ambiguous and hand
   it to Arpit**. Do not adjudicate it and do not restate the threshold in
   looser words. A recorded negative that stops months of building is a
   *successful* outcome.
4. **Pruning work is forbidden outside W-38.** If pruning appears in a diff,
   that is a plan violation, not a bonus.
5. **Docs move with the work, in the same change:** WORKLOG entry every
   substantive exchange · `OPEN-WORK.md` **and** the item's `open/W-nn`
   detail file on any status change · `DOC-REGISTRY.md` row for every doc
   touched · INTERVIEW before a substantive direction change.
6. **When an item closes, delete its detail file and its index row.** The
   record lives in the ADR and the WORKLOG. `docs/open/` holds open work
   only — that is the property that makes the index trustworthy.
7. **Agent-steering files are proposed, never auto-applied.** You may not
   adopt `CLAUDE.md`'s rewrite on your own initiative. Prepare it; Arpit
   decides.
8. **The lab persists.** `~/my_programs/fux-lab` is never deleted or
   rebuilt; a new run is a **new directory inside it**. Run the corpus tiers
   in the cloud, not in the device VM.
9. **Port, don't rewrite.** Anything coming from `archive/v0.26/` comes
   **with its tests**. The archive is reference-only and never modified,
   never imported.

## §4 · Phase 1 — W-22 / M2: the T1 accelerator · **Opus**

Spec: [`../open/W-22-m2-t1-accelerator.md`](../open/W-22-m2-t1-accelerator.md)
· [`../PLAN.md`](../PLAN.md) §M2 · format of record:
[`../compare/index-format.compare.md`](../compare/index-format.compare.md)

### 4.1 What lands

A derived, blocked **term-major** JSONL accelerator under `.fux/runtime/`
(derived plane, `CACHEDIR.TAG`-tagged per ADR-0011) that makes warm `ask`
fast **without changing a single ranked result**.

- Blocked term-major JSONL + offset table; **128-posting block lines with
  integer `mx` skipping** — the measured close of the common-term trap
  (397 ms → 44 ms).
- **The differential law**, below.
- Int-cached Hamming lane over the existing FuxVec 32 B `code` property.
- RRF fusion (k=60), **ported from `archive/v0.26/` with its tests**.
- `find` / `answer` verbs.
- Rebuild path: derived, never committed, reconstructible from the
  committed shards **alone**.

### 4.2 The differential law — the part that must not be got wrong

**Accelerator results ≡ scan results, asserted byte-for-byte as a test.**
Not spot-checked, not "the top-5 match", not tolerance-based. Byte
identity, over every golden and every bench query.

This is the invariant the whole tiering story rests on, and the same
discipline M4's ARC cache will carry. The failure mode is specific and
quiet: an accelerator that is 99 % equivalent produces a fast system whose
every downstream measurement is subtly untrustworthy, and nothing ever
errors. Build the differential harness **before** the accelerator, not
after — if it is written afterwards it will be written to pass.

### 4.3 Definition of done

- [ ] **R3 measured**: warm `ask` ≤ **150 ms** on the RFC corpus (8 872
      docs, manifest-pinned, in the lab) **including worst-case common
      terms**. An average over easy queries is not R3 and reporting one as
      R3 is a law-3 violation.
- [ ] Differential suite green, byte-for-byte, over goldens + bench.
- [ ] Accelerator rebuilds deterministically from committed bytes only.
- [ ] `find` / `answer` behave per the CLI contract.
- [ ] `fux doctor` understands the new derived directory.
- [ ] Playground `known_failure` class 3 (`q008`, `q017`, `q030`, `q031`,
      `q036`) re-run and the XPASS count **reported**. These are targets,
      not DoD — closing zero of them with R3 met is still a passing M2, but
      the number is part of the record.
- [ ] **ADR-0005** written, referenced, accepted.
- [ ] `OPEN-WORK.md` row + `open/W-22-*.md` **deleted**; WORKLOG entry;
      DOC-REGISTRY rows; CHANGELOG.

### 4.4 Hazards specific to this phase

- **JSONL parse tax on real shapes may exceed the bench.** R3 is the
  tripwire; **T2 (M6) is the designed escape and must not be pre-built
  here.** If R3 fails, that is an honest failure ADR, not a licence to
  start mmap segments.
- **If the accelerator is slow, the answer is skipping and blocking —
  never dropping postings.** Law 4.
- The accelerator is derived, so it may hold build-varying ints. **The
  results may not vary.** That distinction is the whole design.
- Do not touch the committed format. It is frozen by
  [ADR-0004](../adr/0004-index-format.md).

### Phase 1 gate

Stop. Report R3 with its worst-case-term numbers, the differential suite
result, and the XPASS count. Then write the **M3 or M4 handoff + prompt
pair** (they may interleave after M2; M4 is the higher-value one and the
one with graduating proposals). Do not begin building it.
