## Traps that will bite you

- **The URL-carry-forward trap.** Once `--refresh-urls` runs, `url:` records
  live in `.fux/index/` and a plain ingest will not remove them. Never commit
  an index produced by a refresh. Handoff §8.
- A failed fetch **keeps** the prior record rather than deleting it — so
  "record exists" does not prove "fetched this run". Start the smoke test from
  the committed, URL-free index.
- Shard files are 256-wide; a 10-doc corpus lights up ~10 of them. Correct,
  not a bug. Say so in `PLAYGROUND.md`.
- `meta = "plain"` affects only `url:` records. Show the `plain` vs `hashed`
  record shapes in `PLAYGROUND.md` and the one-line switch between them —
  hashed is the law's default and must not read as an afterthought.
- Parse `fux ask --json`, never the human output.
