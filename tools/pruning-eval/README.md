# `tools/pruning-eval` — M1, the gate

The experiment that decides whether the index-and-refer architecture gets built
at all: **does KL top-*k* static pruning preserve ranking quality on Fux's
corpora, with Fux's scorer?**

Read [`PRE-REGISTRATION.md`](PRE-REGISTRATION.md) first — metrics, slices, gold
labels and the pass/fail threshold are frozen there, and it was committed
before the first number existed (`git log` is the evidence). The verdict lives
in [`../../docs/adr/0017-pruning-eval-gate.md`](../../docs/adr/0017-pruning-eval-gate.md).

## Design in one line

**One scorer, three arms, only the index differs.** Every arm is scored by the
archived v0.26 `Searcher.search` (BM25F). Nothing under `archive/` is modified —
it is imported and wrapped.

| arm | postings | statistics | role |
|---|---|---|---|
| `baseline` | full | full | the reference |
| `pruned` | top-*k* per document | **recomputed from the pruned postings** | the system we would ship |
| `diag` | top-*k* per document | borrowed from the full index | attribution only, never the verdict |

## Run

```bash
# tests (the selector's contract + the harness self-checks)
archive/v0.26/.venv/bin/python -m pytest tools/pruning-eval/tests -q

# the gate
archive/v0.26/.venv/bin/python tools/pruning-eval/run.py \
    --corpus acme orbit synth --out docs/conformance/<date>-pruning-eval/evidence
```

`--corpus fixture` is the 9-document development corpus; it is **not** a gating
corpus. `acme` and `orbit` are read from `~/my_programs/fux-lab/` and copied,
never ingested in place. `synth` is generated by the archived
`tools/synth_corpus.py` (`--synth-docs`, default 100 000).

Ingested working copies are cached under `~/.cache/fux-pruning-eval/` and reused;
delete that directory to force a rebuild.

## What lives here

| file | role |
|---|---|
| `pruning/kl_select.py` | the selector — **pure, stdlib-only, portable into `src/fux/ingest/` unchanged at M2** |
| `pruning/arms.py` | builds the three arms over the archived `Searcher` |
| `pruning/metrics.py` | hit@5 / P@10 / MRR + the rare-term slice, at document level |
| `pruning/corpora.py` | corpus preparation (black-box CLI ingest) and query sets |
| `run.py` | the harness and its report |
| `tests/` | selector contract + harness self-checks |

## Why the harness is disposable but the selector is not

`kl_select.py` is written as production code — pure, deterministic, tested,
documented — because it gets ported into the engine at M2. Everything else here
is a measuring instrument for one question and is deleted or promoted once
ADR-0017 lands.
