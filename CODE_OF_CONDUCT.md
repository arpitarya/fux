# Code of Conduct

fux follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:**

- Be respectful and assume good intent.
- Critique code and ideas, not people.
- No harassment, insults or personal attacks, in any project space.

**Reporting:** email the maintainer at the address on the [@arpitarya](https://github.com/arpitarya) GitHub profile. Every report is reviewed and kept confidential.

Maintainers may remove comments, commits or contributions that break this code, and may ban contributors who keep breaking it.
