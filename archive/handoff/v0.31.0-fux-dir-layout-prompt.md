## Task

1. **Layout module** (`src/fux/store/fuxdir.py`): `ensure_layout(root)` —
   write-if-missing `.fux/README.md` (the handoff §5.1 table) and
   `.fux/.gitignore` (ONLY `runtime/` and `cache/`, never `*`);
   `derived_dir(root, name)` — mkdir + exact-signature `CACHEDIR.TAG`.
   Call `ensure_layout` at ingest start.
2. **URL list → `.fux/sources/urls`**: one URL per line, `#` comments +
   blanks ignored, non-http(s) line → `FuxError` with `file:lineno`,
   missing file → loud error (only under `--refresh-urls`), empty file
   valid, dedupe + sort before fetching. `[sources.url] urls_file`
   defaults to that path; an inline `urls` key in TOML → `FuxError`
   pointing at the file.
3. **Middleware → `.fux/middleware/cdp.py`**: `git mv` (preserve
   history), then edit; `middleware` config default becomes that path;
   header comment must say it is the consumer's committed file.
4. **Tunables → `fux.toml`**: optional `[sources.url.config]` table
   passed VERBATIM as a dict to a new optional middleware hook
   `configure(config)` — called once after import, before `connect()`.
   Fux validates only "is a table"; it never reads keys inside (the
   PEP 518 tool-table discipline — keeps the adapter cap intact).
   Template constants become defaults `configure` overrides.
5. **Doctor**: error if `git check-ignore` says `.fux/index` is ignored;
   warn on undeclared top-level entries under `.fux/`.

## Constraints (hard)

- $0 / stdlib-only; zero network code in `src/fux/` (sockets live only in
  the consumer's middleware file); middleware imported only under
  `--refresh-urls`.
- Byte-deterministic: sorted urls, no wall-clock, ASCII `\n` writes for
  the generated files (the v0.30.0 Windows-console lesson).
- Never overwrite `.fux/README.md`, `.fux/.gitignore`, or the middleware
  if present.
- Do NOT touch: `archive/**`, `tools/pruning-eval/**`,
  `store/canonical.py` semantics, shard count, ADR-0004's frozen fields,
  ADR numbering (0005–0009 stay reserved).
- No back-compat shims for the root `cdp_middleware.py` / inline `urls`
  (unreleased, hours old — hard-move).
- Out of scope: `runtime/`/`cache/` contents (M2/M4), adapters, crawling,
  MCP.
