# Claude Code prompt — v0.30.0 M0+M1 (the T0 slice)

*Run with **Sonnet**. One checkpoint uses Opus — it's marked.*

---

You are building the first real code of the Fux v0.30 rebuild. The full
spec is `docs/archive/v0.30.0-m1-t0-slice-handoff.md` — **read it first
and treat its Definition of Done, Scope, and Non-negotiables as binding.**

What you are building, in one sentence: `fux ingest` walks this repo's
docs into a canonical, committed, sharded JSONL index, and `fux ask`
answers questions from it by deterministic scan, with citations — no
accelerator, no pruning, no network.

Two measured facts shape everything: pruning FAILED its gate
(`docs/adr/0003-pruning-criterion-rerun.md` — the index carries **full
postings**), and the tiered-JSONL format won on benchmarks
(`docs/compare/index-format.compare.md` — §5 is the schema, §7 the binding
rules). You are implementing decided things. Do not re-litigate them.

## Task — four phases

**Phase 0 — ground check.** `git status` clean; latest commit is the
ADR-0003 FAIL commit or later. If the tree is dirty, stop and tell me.

**Phase 1 — M0 scaffold.** `src/fux/` package per handoff §2; pyproject
`0.30.0.dev0`, hatchling, zero runtime deps; `fux --version`, `fux doctor`;
fresh CHANGELOG; `.github/` fixed for the new tree. Pause here only if CI
can't go green.

**Phase 2 — the store, then STOP for review.** Implement `store/`: the
canonical writer/reader exactly per handoff §5 — NFC normalization, sorted
keys, `(",",":")` separators, `ensure_ascii=False`, shard by
`blake2b(id,1)`, lines sorted by `id`, `_format` header first line,
16-hex term hashes, loud collision failure, no floats/nulls/wall-clock in
committed bytes. Write its tests including the crafted-collision case.
**Checkpoint: hand `store/` + tests to a fresh Opus session for review
against handoff §5/§6 before proceeding.** Canonicalization bugs here
surface as merge-driver corruption at M5 — this is the one place we spend
the expensive model.

**Phase 3 — ingest + ask.** Git-dir adapter (sorted walk of `[sources]`
dirs; skip-with-reason for binary/non-UTF8/empty); extractors: ported
tokenizer → `terms`+`wlen`, title + heading `phrases`, `ref`/`tag`/`code`
edges, FuxVec `code`; incremental by `sha`. Then `fux ask`: bytes-level
prefilter scan over shards, parse candidates only, ported BM25F with
df/N/avg-wlen computed in-pass (never stored), deterministic `id`
tie-break, top-k with citations.

**Phase 4 — dogfood + verdicts.** `fux ingest` on this repo (`docs/`,
`README.md`, `CLAUDE.md`). Run the three fixed R2 questions from handoff
§9 — they are frozen; do not substitute easier ones. Then the
**playground**: `cd examples/playground && fux ingest`, commit the
resulting `.fux/index/` (it is the format's visible demo), verify every
command in `PLAYGROUND.md` works exactly as written and its three
questions cite correctly (the superseded ADR pair must both surface).
The 20 AcmePay docs are a fixture — if something fails, fix the engine or
PLAYGROUND.md, never the corpus. Assert R1
(double-ingest → identical shard sha256s) locally and wire the
ubuntu+macos CI matrix. Write **ADR-0004** freezing schema, canonical
rules, unicode policy, and the analyzer version — citing the compare doc.
Update README status, CHANGELOG, OPEN-WORK (W-items + R1/R2 measured),
WORKLOG, DOC-REGISTRY. CLAUDE.md changes go as a **proposed diff for my
review — never applied silently.**

## Constraints (hard)

- **Stdlib only** in `src/fux/`. Zero runtime dependencies.
- **Determinism is the product:** same checkout → byte-identical shards on
  any OS. NFC-normalize text at ingest; sorted walks; no randomness; no
  timestamps in committed bytes.
- **Full postings. No pruning, no term selection, of any kind.**
- **No accelerator work** — no term-major files, no `mx`, no offset
  tables, no `derive/` beyond an empty stub. Scan latency ~100–200 ms on
  this corpus is correct M1 behavior.
- **No dense/graph query lanes** — write `code` and `edges` properties;
  use neither in `ask`.
- **Do not touch** `archive/`, `docs/paper/`, compare-doc verdicts, or the
  frozen PRE-REGISTRATION files.
- `.fux/index/` is committed; everything else under `.fux/` gitignored
  from day one.

## Guardrails

- Ask before: any new dependency, any schema field not in the spec, any
  edit under `archive/`, or applying anything to CLAUDE.md.
- If the spec conflicts with what a ported module actually does, **stop
  and ask** — the resolution goes in ADR-0004 either way.
- If R1 fails on macOS, that is the design's foundational risk surfacing —
  do not paper over it with a re-sort or a filter; diagnose the
  normalization difference and bring it to me with the fix proposal.
