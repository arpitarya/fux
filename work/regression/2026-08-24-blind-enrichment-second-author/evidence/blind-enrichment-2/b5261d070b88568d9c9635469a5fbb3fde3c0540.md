Command-line usage reference for the platform's operator tool: the available
subcommands, their syntax and options, which invocations mutate state, and what
each exit status means when a command is refused rather than simply failing.
Answers "what command do I run to..." questions about checking release state,
halting or resuming a rollout, reverting, shipping a version, adjusting resource
limits, and looking up a service's stated sensitivity and expiry window. Also
warns about the near-identical pair of revert invocations whose surge option
differs, and where machine-readable output and simulation support exist. Useful
for scripting, troubleshooting refusals, and cheat-sheet lookups during an
incident.
