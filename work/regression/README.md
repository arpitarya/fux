# `work/regression/` — the measurement evidence store

**How to use this directory.** This is what other docs **point at** when they
need grounding. An ADR's reference, a status claim, a verdict in `compare/` —
all of them may cite a run here, and none of them may cite an archived doc
instead. A run filed here is the only kind of evidence that stays valid.

*Every measurement run against a real or synthetic corpus is filed here:
the run's own report, an `ANALYSIS.md` that turns the numbers into specific
decisions, and the raw evidence under `evidence/`. Binding, per CLAUDE.md —
engine changes are made from measured data, not from memory.*

**The measurement environment is scratch; this directory is not.**
`~/my_programs/fux-lab/` holds one directory per corpus (its own venv, corpus,
baselines) and commits nothing. What survives a run is what lands here.

**This directory persists across rebuilds.** The v0.19–0.26 runs are evidence
about an engine that is now archived, but the *corpora*, the eval pairs and the
measured baselines they establish were the instrument v0.30 measured against.

the 2026-08-20 `fux-lab` wipe along with their generator (`make_repo.py`) and
have not been rebuilt — `tools/pruning-eval/` still hard-codes reading them
and cannot run until someone generates replacements (SETUP-LAB). This line

## Per-run contract

| # | artifact | what it must contain |
|---|---|---|
| 1 | `<date>-<run>/` | one directory per run, dated |
| 2 | `report.md` | the run's own output, unedited (corrections noted, not silently applied) |
| 3 | `ANALYSIS.md` | the diagnosis → **specific** changes, each with a repro command; unresolved causes stated as unresolved |
| 4 | `evidence/` | the primary data the analysis rests on |
| 5 | `VERDICT.md` | **only when the run rules on a pre-registered threshold** — the ruling, its verdict, and the frozen pre-registration it was ruled against |
| 6 | a row below | plus a DOC-REGISTRY bump, same change |
| 7 | `classification:` | **`blind` or `informed`, in the report's frontmatter, plus an `## Authorship` section** — measured runs filed from **2026-08-25** only; a surface capture is exempt |

**One directory can be legally half-empty: pre-registered, not yet measured.**
A directory holding a frozen `PRE-REGISTRATION.md` and **no report** owes
nothing else — rows 2, 3, 4 and 7 do not apply, because nothing has been
measured and there is nothing to classify. Row 6 still does: a threshold nobody
can find is as useless as a run nobody can find.

- This is the method, not a gap. The threshold is committed **first** and never
  moves; the measurement comes later, and can be blocked for weeks on an
  environment that does not exist yet.
- ⚠ **It is legal only while there is no report.** The moment one lands the
  full contract applies again — this is not a way to file a number without its
  evidence.

**The reproduce command must actually reproduce.** A run whose numbers cannot
be regenerated is an anecdote.

**Every measured run is `blind` or `informed`.** A run is **blind** only if
*every* artifact it depends on — corpus enrichment, the enrichment prompt,
chunking and index configuration, retriever and reranker settings, **and the
analysis** — was authored with no access to the evaluation queries, the
judgments, prior per-query scores, or any derived report of them. Anything else
is **informed**. An informed run is **reclassified, not banned**: filed, listed,
cited, allowed to inform the corpus, and **never compared with a blind run or
used to state a delta**. That is TREC's manual/automatic split, in force there
since 1994.

The report names **who authored each artifact and what they could reach**
(*queries / judgments / prior scores / none*), under an `## Authorship`
heading. An informed number is **not** an "upper bound" — that claims a bounded
magnitude a leak does not have — it is **"not a generalisation estimate."** And
a delta below the set's resolution is reported as **no detected change**;
provisionally, on a 50-query set, nothing under ±2 queries counts.

**The rule is baselined at 2026-08-25 on the run directory's own date**, and the
runs above it are exempt for a reason worth stating: **a filed report is frozen**,
and editing the evidence to satisfy a rule written afterwards is the same class
of act the rule exists to prevent. Ruled by Arpit (W-78 ruling 2); owned by
[ADR-RS](../../docs/adr/0036_predictions.md) decisions 11-15; checked by
[`tests/test_regression_runs.py`](../../tests/test_regression_runs.py).

⚠ **Two parts of the accepted rule are NOT built** — a **sealed** query subset
and the **decoy / placebo** controls — and are owed as
[W-81](../open/W-81-the-sealed-set-and-the-two-controls.md). Nothing may cite
them as in force.

**A verdict is cited, never replaced.** When a run adjudicates a
pre-registered prediction, that ruling is a `VERDICT.md` beside its evidence —
`type: Verdict`, with the prediction id and the pre-registration path in its
frontmatter. It is deliberately **not** an ADR: an ADR records a decision
someone can later supersede, and nothing supersedes a measurement except a
better measurement, which is a new run with its own verdict. The two P1
verdicts were ADRs until 2026-08-18 and were converted for exactly this reason.
The *decisions* that rest on a verdict stay in `docs/adr/`, citing it.

**Not every entry is a measurement.** A *surface capture* — a verbatim record
of what a command prints — belongs here too, because other docs cite it as
grounding and it must be reproducible for that to mean anything. Say which it
is at the top of the report: a capture gates no prediction and pre-registers
no threshold, and calling it a measurement would be the kind of overclaim the
pre-registration discipline exists to stop.
