## ⚠ The guard did not fire

`.claude/hooks/guard-golden-traversal.sh` (W-223's hard guard) is registered in
`.claude/settings.json`. Replayed alone through the hook, the grep line is
**denied** (exit 2), with or without its `| grep -v` tail. In the session it ran
as the **last line of a multi-line Bash command** that began
`cd … && git mv … && python3 - <<'EOF'`, with a heredoc Python body, followed by
a second `grep -n` line. Whole, that command was **allowed**.

I have not isolated which part of the command defeats the parser. When I tried
to replay the whole command through the hook, the auto-mode classifier refused
it as probing a security guard for a bypass. I stopped there, so the diagnosis
is Arpit's to authorise.
