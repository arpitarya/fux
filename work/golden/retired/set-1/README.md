# set-1 — RETIRED golden data

🔴 **This set no longer carries a golden claim, and no number measured on it
is evidence about the engine's quality.** Its questions and expected values
are open: any session may read them, in any state, as ordinary regression and
feature-test data. That is exactly why they are no longer a benchmark — the
model family that reads them also tunes against them.

⚠ **`expected.jsonl`, not `answers.jsonl`.** `.gitignore` carries
`**/answers.jsonl` so that a key file cannot be committed at any depth; the
retired tier is named around that guard rather than through it.

Retired under [L11](../../../../records/0012_LAW-11-sealed-answer-key.md)
decision 14 by `just golden-retire`. The sealed successor is the next
generation, named `set-<gen>-<x|u>`.
