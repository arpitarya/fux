# Lane qualification LQ-53

Record **LQ-53** qualifies one lane for one product class, one season and one vehicle class. Lane records are numbered one after another and the numbers differ by one digit; quote the number printed on the dispatch note, never the lane name alone.

## 1. Lane

| field | value |
|---|---|
| origin | Pune HQ |
| destination | Nagpur DC |
| route | via Shirdi, then the Samruddhi expressway |
| distance | 698 km |
| product class | pharma critical, chilled |
| vehicle class | owned_reefer_chilled |
| season profile | summer, April to June |
| trial runs | 3, from 6 to 18 April 2026 |

## 2. Score

2.1. LQ-53 scores an LRS of 14 of 25. The expressway removed the Jalna stop and one door opening, and cut the peak-ambient and driver-change scores.

2.2. LQ-53 replaces LQ-51 for this lane.

2.3. LRS 14 is below 16, so no relief point is named for 2026. The two-driver rule for a night pharma segment is not affected: it comes from the driver hours policy, not from the score.

## 3. Trial results

| measure | result |
|---|---|
| warmest body reading | +6.1 C, run 1, Samruddhi tunnel section |
| longest telemetry gap | 15 minutes, Samruddhi tunnel section |
| PCH used | 40 minutes |
| door openings per run | 1 |

## 4. Conditions

4.1. PCH 40 minutes before loading at Pune. The 30 minutes of LQ-51 no longer applies.

4.2. Every run carries one validated passive shipper as backup, hired per trip. Its gel packs must have completed their Shipper Conditioning Time (SCT) of 18 hours at +5.0 C before the run is booked.

4.3. A USB logger travels in the load compartment on every run. The tunnel gap is written as missing, never filled.

4.4. Departure checks for this lane are on [the pink card](30-pharma-night-dispatch-checklist.md).

4.5. LQ-53 is valid for the 2026 summer season only.
