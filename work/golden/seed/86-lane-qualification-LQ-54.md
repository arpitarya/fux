# Lane qualification LQ-54

Record **LQ-54** qualifies the frozen lane from Nagpur DC to the restaurant-chain depots in Raipur. It is a single-drop run with one vehicle class and one season.

## 1. Lane

| field | value |
|---|---|
| origin | Nagpur DC |
| destination | Raipur customer depots |
| route | via Bhandara, Deori, Rajnandgaon and Durg |
| distance | 291 km |
| product class | frozen food |
| vehicle class | owned_reefer_frozen |
| season profile | monsoon, June to September |
| trial runs | 3, from 9 to 23 June 2026 |

## 2. Score

2.1. LQ-54 scores an LRS of 11 of 25. No factor scored above 3. The highest was telemetry dead zones, from the forest stretch around Deori.

2.2. The run fits inside one day for one driver, with no driver change and no planned stop longer than a fuel halt.

## 3. Trial results

| measure | result |
|---|---|
| warmest body reading | -19.2 C, run 3, in the Durg toll queue |
| longest telemetry gap | 6 minutes, near Deori |
| PCH used | 50 minutes |
| door openings per run | 1 |

3.1. All three runs used RF-120. The only door opening on each run was at the Raipur depot.

3.2. Run 2 left Nagpur an hour late after a hold at dock 5 and still reached Raipur inside the depot's receiving window.
