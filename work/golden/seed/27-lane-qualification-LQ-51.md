# Lane qualification LQ-51

Record **LQ-51** qualifies one lane for one product class, one season and one vehicle class. Lane records are numbered one after another and the numbers differ by one digit; quote the number printed on the dispatch note, never the lane name alone.

## 1. Lane

| field | value |
|---|---|
| origin | Pune HQ |
| destination | Nagpur DC |
| route | via Ahmednagar, Aurangabad and Jalna |
| distance | 712 km |
| product class | pharma critical, chilled |
| vehicle class | owned_reefer_chilled |
| season profile | summer, April to June |
| trial runs | 3, from 7 to 19 April 2025 |

## 2. Score

2.1. The Lane Risk Score (LRS) is the sum of five factors, each scored 1 to 5: peak ambient, longest stop without shore power, telemetry dead zones, planned door openings, and driver changes.

2.2. LQ-51 scores 17 of 25.

2.3. A lane scoring 16 or more runs only with a named relief point. For LQ-51 the relief point is the Jalna fuel plaza.

## 3. Trial results

| measure | result |
|---|---|
| warmest body reading | +6.8 C, run 2, during the Jalna stop |
| longest telemetry gap | 9 minutes, near Sindkhed Raja |
| PCH used | 30 minutes |
| door openings per run | 2 |

## 4. Conditions

4.1. PCH 30 minutes before loading at Pune.

4.2. A USB logger travels in the load compartment on every run.

4.3. Night segments follow the [Driver Hours and Road Safety Policy](08-driver-hours-and-safety-policy.md); this record does not change them.

4.4. LQ-51 is valid for the 2025 summer season only.
