# Seal handling card, gate cabin

Kept on the gate cabin counter beside the seal register.

## Fitting

1. Next seal in number order from the open book. Never skip a number.
2. Owned reefer: bolt seal on the rear door hasp. Hired truck: cable seal.
3. Seal number on the dispatch note and in QCL-F-35 before the vehicle moves.
4. Photograph the seal with the dock clock in frame.
5. Spoiled while fitting: cut it, bag it with the stub, write VOID in QCL-F-35 and return it to Stores within 72 hours.

## At the destination

6. Receiver reads the number before cutting. Mismatch or broken seal: photograph it and call the QA desk on extension 440 before the doors open.
7. Cut seals stay in the trip bag for 7 days.
