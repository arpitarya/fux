# Lane qualification LQ-52

Record **LQ-52** qualifies one lane for one product class, one season and one vehicle class. Lane records are numbered one after another and the numbers differ by one digit; quote the number printed on the dispatch note, never the lane name alone.

## 1. Lane

| field | value |
|---|---|
| origin | Nagpur DC |
| destination | Nashik customer depots |
| route | via Amravati, Aurangabad and Sinnar |
| distance | 684 km |
| product class | dairy, milk and paneer |
| vehicle class | owned_reefer_chilled |
| season profile | monsoon, July to September |
| trial runs | 3, from 7 to 25 July 2025 |

## 2. Score

2.1. LQ-52 scores an LRS of 19 of 25, the highest of any qualified lane, because fog, the Sinnar police holding point and two telemetry dead zones each scored 4 or more.

2.2. A lane scoring 16 or more runs only with a named relief point. For LQ-52 the relief point is the Sinnar toll rest area.

## 3. Trial results

| measure | result |
|---|---|
| warmest milk reading | +4.6 C, run 3, during a 38-minute police hold |
| longest telemetry gap | 14 minutes, before Sinnar |
| door openings per run | 6, multi-drop |

## 4. Conditions

4.1. From 1 July to 30 September LQ-52 runs with two drivers named on the dispatch note, whatever the departure time.

4.2. Any milk spill in the body is washed out under [the Sunday sheet](32-reefer-washdown-and-sanitation-procedure.md) before the body carries paneer again; a spill is never wiped and reloaded.

4.3. A USB logger travels in the load compartment on every run.

4.4. LQ-52 is valid for the 2025 and 2026 monsoon seasons unless the route changes.
