### R-3 · W-107 Phase 0 — the `log()` pick (0d) — 🟢 one word

**Proposal: (b) — tolerance at `round(9)`.** Fill
[`PRE-REGISTRATION-NODE.md`](../benchmark/PRE-REGISTRATION-NODE.md) §2's

### R-4 · W-110's gate — which `k` (0d) — 🔴

**Proposal: the gate is VOID, not judged. W-110 stays shipped. The next
enrichment pre-registration fixes `k` before any number exists.**

- **Why void.** A bar of `net ≥ 6 on recall@k` with no `k` is not a bar;
  ruling `k = 1` now (PASS) or `k = 5` now (FAIL) are both the post-hoc move
  the pre-registration discipline forbids, and a void gate is the only
  outcome that moves no threshold.
- **Why it stays shipped.** Arpit's standing rule: *features built are kept*.
  And the two facts that make keeping it safe are not in dispute — **0 down at
  every `k`**, and a **placebo that moved nothing at any `k`**.
- **What fixes `k` next time, and its provenance.** [SR-WORK-QUALITY](../../records/0056_WORK-quality.md)
  reports `recall@k` as a curve and names no single `k`, so nothing
  independent of the numbers picks one. **A structural candidate: `k = 3`,
  because it is `answer`'s window since W-108 (`ANSWER_TOP = 3`)** — the
  slot a caller actually reads. ⚠ **This author has seen the numbers, so
  that suggestion is tainted by construction**: Arpit adopts it or names
  another, and it binds the *next* run only.
- **Opus.** No `VERDICT.md` for the doc2query run (it stays as filed,
  *ambiguous*); SR-ENRICH gains a decision recording *gate void, feature
  kept, `k` fixed in advance from now on*; SR-RS gains the rule *a paired
  bar names its `k`*; W-110's detail file goes to `archive/open/` with the
  IMPLEMENTATION row already there.

### R-10 · The 7 `partial` goldens (8d)

used**, with the adjudication rule fixed before the reader starts.

- **The protocol.** A fresh agent session receives the ten corpus documents
  and the seven queries (`q020 q021 q027 q032 q039 q042 q050`) — no scores,

- **The rule, written first.** A document is relevant if **two of three**

- **Why not a human.** The blind-authorship compare doc is the precedent:
  what matters is what the reader could reach, not whether it breathes.
- **Opus.** Run it; file under `regression/` as `blind` for the reader and
  `informed` for the adjudication; `recall@k` re-reported over the queries
